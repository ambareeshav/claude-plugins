# Ambareesha's Claude Code plugins

One marketplace for all my Claude Code plugins. Add it once, then install whichever you want.

```
/plugin marketplace add ambareeshav/claude-plugins
```

| Plugin | What it does | Install |
|---|---|---|
| [rvr](https://github.com/ambareeshav/rvr) | Research, Validate, Report. End a message with `rvr` to pressure-test a design before you commit to it. | `/plugin install rvr@ambareeshav` |
| [idd](https://github.com/ambareeshav/idd) | Ideate, Debate, Discuss. End a message with `idd` and Claude only discusses and plans, with no code changes. | `/plugin install idd@ambareeshav` |
| [spotify](https://github.com/ambareeshav/claude-spotify-mod) | Icon-only Spotify controls above the prompt, with a fullscreen sidebar for your playlists. | `/plugin install spotify@ambareeshav` |
| [prs](https://github.com/ambareeshav/claude-pr-review-mod) | Dock a pull request review (diff, file tree, commits) beside your session via `/prs`, for Azure DevOps or GitHub. | `/plugin install prs@ambareeshav` |

From the terminal, use `claude plugin marketplace add ambareeshav/claude-plugins` and `claude plugin install <name>@ambareeshav`.
